\# API de Gestão de Estoque e Pedidos



API REST desenvolvida com Python, Django REST Framework e PostgreSQL.



\## Objetivo



Gerenciar produtos, fornecedores, clientes, pedidos e movimentações

de estoque.



\## Funcionalidades



\- Cadastro e consulta de produtos

\- Gestão de clientes e fornecedores

\- Criação e cancelamento de pedidos

\- Controle de estoque

\- Autenticação e permissões

\- Histórico de movimentações

\- Testes automatizados



\## Tecnologias



\- Python

\- Django

\- Django REST Framework

\- PostgreSQL

\- Pytest

\- Docker

\- GitHub Actions
